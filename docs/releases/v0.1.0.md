# v0.1.0 — Production readiness baseline

Release date: 2026-08-01

## Highlights

- Public SSR portfolio and authenticated administration frontend.
- Spring Boot API with PostgreSQL, Flyway migrations, CSRF-protected admin
  sessions, login throttling, and contact-form abuse protection.
- Docker Compose deployment with automatic HTTPS through Caddy and isolated
  application, database, and monitoring networks.
- Prometheus, Alertmanager, Grafana, Loki, Alloy, Blackbox Exporter, and Sentry
  integration points.

## Release safeguards

- Unit, integration, PostgreSQL migration, backup/restore, Chromium E2E, and
  axe accessibility tests.
- Gitleaks, npm production audit, Trivy Maven/filesystem scanning, and Trivy
  image scanning.
- Automated dependency updates through Dependabot.
- CSP, Permissions Policy, anti-indexing headers for admin, and a public
  contact-form privacy notice.
- Loki 3.7.4 has two package- and path-scoped Trivy exceptions for upstream
  `x/text` and gRPC findings. They expire on 2026-08-15, so CI will require a
  patched Loki release or an explicit security review after that date.

## Deployment notes

- Use `RELEASE_VERSION=v0.1.0` consistently for application images and Sentry
  releases.
- Production domains, TLS, external PostgreSQL port checks, Sentry delivery,
  Alertmanager webhook delivery, external uptime monitoring, and Lighthouse
  must be verified on the deployment host before announcing the release.
- Follow `docs/release-rollback.md` and retain the previous immutable image set
  until the post-release observation window is complete.
